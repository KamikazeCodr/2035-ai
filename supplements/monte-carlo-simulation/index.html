The 800,000-Sample Monte Carlo Engine & Geopolitical Shock Covariance

Probabilistic Simulation & Bayesian SIR • N = 800,000 Iterations

Forecasting a complex decade-long socio-technical transition cannot be done through point estimates. Deterministic point forecasts either underestimate systemic fragility or produce hysterical worst-case scenarios without assigned probabilities.

To capture the non-linear interactions of threat actor scaling, defense deployment, and geopolitical conflict, I built an 800,000-sample probabilistic Monte Carlo simulation. The engine models parameter uncertainty over lognormal and logit margins, introduces a correlated macroeconomic shock covariance matrix, and conditions prior distributions against audited 2024–2025 observations using Bayesian Sequential Importance Resampling (SIR).

The Simulation Principle: Real-world crises do not happen independently. If a severe geopolitical conflict erupts in the Taiwan Strait, semiconductor hardware output drops, nation-state cyber commands mobilize offensive swarms, and enterprise SOC analyst triage exhausts simultaneously. The engine enforces an empirical macro-shock correlation parameter (\(\rho = 0.30\)) so that bad-world factors cluster realistically rather than artificially cancelling each other out.

1. Correlated Normal Shock & Quantile Mapping

In standard independent sampling (\(\rho = 0\)), drawing 45 parameters independently causes the Law of Large Numbers to smooth out all tail risk: an extreme draw in actor concurrency is negated by an extreme draw in defensive patching, producing an artificially narrow distribution.

I resolve this by formulating a shared macroeconomic crisis shock vector \(\mathbf{z}\) using a one-factor Cholesky decomposition:

$$z_i = \sqrt{\rho}\,\epsilon_{\text{macro}} + \sqrt{1 - \rho}\,\epsilon_i, \quad \rho = 0.30, \quad \epsilon_{\text{macro}}, \epsilon_i \overset{\text{iid}}{\sim} \mathcal{N}(0, 1)$$

Where \(\epsilon_{\text{macro}}\) is a common global crisis shock and \(\epsilon_i\) is an idiosyncratic factor shock. The resulting correlated standard normal score \(z_i\) is mapped into bounded parameter space via explicit quantile inverse transforms:

  • Lognormal Positive Quantities (e.g., Operator Pool Size, Campaigns per Year, Unit Loss): $$\theta_i = \exp\left( \mu_i + \sigma_i \cdot z_i \right)$$
  • Bounded Fractions & Defense Elasticities (e.g., Exploit Yield, Unpatched Exposed Surface): $$\theta_i = \frac{1}{1 + \exp\left( -(\mu_i + \sigma_i \cdot z_i) \right)}$$

2. Bayesian SIR Conditioning Filter

To prevent uncalibrated priors from distorting near-term projections, my pipeline applies a Bayesian Sequential Importance Resampling (SIR) filter. Prior parameter particles (\(N = 100,000\)) are reweighted by comparing simulated near-term losses against audited observations from the 2024 FBI IC3 complaint index and the 2024 IBM Cost of a Data Breach audit:

$$w_m \propto \exp\left( -\frac{1}{2} \sum_{t=2024}^{2025} \left( \frac{L_{\text{sim}}(t) - L_{\text{obs}}(t)}{\sigma_{\text{obs}}} \right)^2 \right)$$

Conditioning maintains an Effective Sample Size (\(\text{ESS}\)) of 84,797 surviving particles out of 100,000 (an 84.8% survival efficiency), ensuring that the Monte Carlo distribution is strictly anchored to current real-world baseline telemetry before branching into 2026–2035.

def lnorm(rng, n, q):

    """Sample from lognormal distribution specified by p10, p50, p90 quantiles."""

    lo, mid, hi = q

    scale = (math.log(hi) - math.log(lo)) / (2.0 * Z)

    return mid * np.exp(scale * rng.standard_normal(n))





def lgnorm(rng, n, q):

    """Sample from logit-normal distribution specified by p10, p50, p90 quantiles."""

    lo, mid, hi = q

    scale = (logit(hi) - logit(lo)) / (2.0 * Z)

    return inv_logit(logit(mid) + scale * rng.standard_normal(n))





def assign_branches(n, rng_s5, S5, h_independent=0.0, seed=7):

    """
    Assign per-sample geopolitical branch, conflict onset year W, and recovery duration R.
    When S5 is disabled, reproduces baseline allocation (weights: B-02 = 0.7 cap / 0.3 B-01).
    """

    if not S5:

        weights = P.BRANCH_WEIGHTS

        order = ["B-03", "B-04", "B-01", "B-05", "B-02"]

        probs = [weights[b] for b in order]

        br = rng_s5.choice(5, size=n, p=probs)

        capfail = (br == 4) & (rng_s5.random(n) > 0.7)

        br = np.where(capfail, 2, br)

        return br, np.full(n, 2032), np.full(n, 4.0), {}



    h = np.minimum(lnorm(rng_s5, n, HYP["hazard"]), 0.5)

    hit = rng_s5.random((n, 9)) < h[:, None]

    has = hit.any(1)

    W = np.where(has, 2027 + hit.argmax(1), 9999)



    plateau = rng_s5.random(n) < lnorm(rng_s5, n, HYP["tp"])

    sp = np.vstack([lnorm(rng_s5, n, q) for q in HYP["split"]])

    sp = sp / sp.sum(0)



    u = rng_s5.random(n)

    cat = np.where(u < sp[0], 0, np.where(u < sp[0] + sp[1], 1, 2))



    d10 = lnorm(rng_s5, n, HYP["d10"])

    pcap = np.interp(d10, [0.05, 0.15, 0.30], [0.9, 0.7, 0.5])

    holds = rng_s5.random(n) < pcap

    R_ = lnorm(rng_s5, n, HYP["recov"])



    br = np.zeros(n, dtype=int)

    war = has & ~plateau



    br[plateau] = 1

    br[war & (cat == 0)] = 2

    br[war & (cat == 1)] = 3

    br[war & (cat == 2)] = np.where(holds[war & (cat == 2)], 4, 2)



    # Sovereign containment failure dynamics: early reversion profile

    late = rng_s5.random(n) > 1.0 / (2.0 - d10)

    failcap = war & (cat == 2) & ~holds



    # Autonomous diffusion hazard: independent state release/cap probability

    if h_independent > 0.0:

        r_ind = np.random.default_rng(seed + 8888)

        hit_ind = r_ind.random((n, 9)) < h_independent

        has_ind = hit_ind.any(1) & ~has & ~plateau

        W_ind = np.where(has_ind, 2027 + hit_ind.argmax(1), 9999)

        W = np.where(has_ind, W_ind, W)

        br[has_ind & (cat == 0)] = 2

        br[has_ind & (cat == 2)] = np.where(holds[has_ind & (cat == 2)], 4, 2)

        ind_late = r_ind.random(n) > 1.0 / (2.0 - d10)

        failcap_ind = has_ind & (cat == 2) & ~holds

        late = late | (ind_late & failcap_ind)



    return br, W, R_, {

        "h": h,

        "plateau": plateau,

        "has_war": has,

        "cat": cat,

        "holds": holds,

        "d10": d10,

        "late": late & failcap,

    }





def weights_year(y, br, W, Rr, S5, late=None):

    """
    Calculate time-dependent weights for conflict, proliferation, and sovereign containment.
    """

    war = np.where(y >= W, np.clip(1.0 - (y - W) / Rr, 0.0, 1.0), 0.0)



    if S5:

        # Dynamic onset: compute shock starts at W; policy response manifests with one-year lag

        prolif = np.where(y == W + 1, 0.3, np.where(y > W + 1, 1.0, 0.0))

        cap = np.where(y == W + 1, 0.5, np.where(y > W + 1, 1.0, 0.0))

        lateyr = (y == W + 1) & (late if late is not None else False)

    else:

        # Baseline profile

        prolif = np.where(y == W, 0.3, np.where(y > W, 1.0, 0.0))

        cap = np.where(y == W, 0.5, np.where(y > W, 1.0, 0.0))

        lateyr = np.zeros(len(br), dtype=bool)



    slow = min(1.0, max(0.0, (y - 2026) / 5.0))

    return war, prolif, cap, slow, lateyr





def modifiers(sector, name, kind, br, war, prolif, cap, slow, lateyr):

    """
    Calculate location shift (log multiplier or logit shift) and spread addition per sample world.
    """

    n = len(br)

    m = [np.zeros(n) for _ in range(3)]

    isw = (br >= 2)

    b4 = (br == 1)

    b1 = (br == 2) & ~lateyr

    b2 = (br == 4) | ((br == 2) & lateyr)



    if kind == "lognormal":

        if name == "capable_actors":

            for i in range(3):

                m[i] += b4 * slow * math.log(0.4 if sector == "ics" else 0.6)

                m[i] += b1 * prolif * math.log(PROLIF_ACT[sector]) + b2 * cap * math.log(CAPM[sector][i])

        if name == "campaigns_per_actor":

            for i in range(3):

                m[i] += (

                    b4 * slow * math.log(0.5)

                    + isw * war * math.log(0.75)

                    + b1 * prolif * math.log(1.3)

                    + b2 * cap * math.log(CAMP_CAP[i])

                )

    else:

        if name == "success_given_exposure":

            for i in range(3):

                m[i] += -0.5 * slow * b4 - 0.25 * isw * war + 0.4 * prolif * b1 + SUCC_CAP[i] * cap * b2

        if name == "defense_containment":

            for i in range(3):

                m[i] += -0.2 * slow * b4 - 0.25 * isw * war



    return m[1], (m[2] - m[0]) / (2.0 * Z)





def base_ms(sector, name, y, cal):

    """Compute base distribution parameters (mu, sigma) and factor distribution kind."""

    fac = P.SECTORS[sector][name]

    q, kind = R.base_q(fac, y, cal, name)



    if kind == "lognormal":

        return math.log(q[1]), (math.log(q[2]) - math.log(q[0])) / (2.0 * Z), kind



    return logit(q[1]), (logit(q[2]) - logit(q[0])) / (2.0 * Z), kind





def run(

    n,

    seed=7,

    SW=None,

    ref=None,

    cal=None,

    keep=(2025,),

    diffusion_uplift=1.0,

    defender_uplift=1.0,

    patch_lag_factor=1.0,

    h_independent=0.0,

):

    """
    Main Monte Carlo sampler. Returns loss trajectories and quantile decompositions.
    """

    SW = {**SW_ALL_OFF, **(SW or {})}

    cal = cal or {s: 1.0 for s in SECT}



    ss = np.random.SeedSequence(seed)

    st = [np.random.default_rng(x) for x in ss.spawn(6)]

    rng, r5, r7, r4, rus, rd7 = st



    br, W, Rr, h5 = assign_branches(n, r5, SW["S5"], h_independent=h_independent, seed=seed)

    incr = {s: (lgnorm(r7, n, INCR[s]) if SW["S7"] else np.ones(n)) for s in SECT}

    us = lnorm(rus, n, HYP["us_share"])

    zD = rd7.standard_normal(n)

    Vp = {s: lnorm(r4, n, VPOOL[s]) for s in SECT}

    beta = lnorm(r4, n, BETA)



    phi_w = rng.choice(np.array(PHI_CHOICES), size=n) if SW["S1"] else None

    c = rng.standard_normal(n) if SW["S1"] else None

    idio = {(s, f): rng.standard_normal(n) for s in SECT for f in P.SECTORS[s]} if SW["S1"] else {}



    out = {

        "L": {s: {} for s in SECT},

        "b": {s: {} for s in SECT},

        "rep": {s: {} for s in SECT},

        "parts": {},

        "br": br,

        "W": W,

        "us": us,

        "incr": incr,

        "hyper": h5,

        "zD": zD,

        "phi": phi_w,

        "beta": beta,

        "Vp": Vp,

    }



    cumS = {s: np.zeros(n) for s in SECT}

    Lprev = {s: None for s in SECT}



    for k, y in enumerate(YEARS):

        if SW["S1"]:

            if k > 0:

                c = phi_w * c + np.sqrt(1.0 - phi_w ** 2) * rng.standard_normal(n)

        else:

            c = rng.standard_normal(n)



        war, prolif, cap, slow, lateyr = weights_year(y, br, W, Rr, SW["S5"], h5.get("late"))

        itact = None



        sector_order = [x for x in SECT if x != "ics"] + [x for x in SECT if x == "ics"]

        for s in sector_order:

            tot = np.ones(n)

            d = {}



            for name in P.SECTORS[s]:

                mu, sg, kind = base_ms(s, name, y, cal[s])

                loc, spr = modifiers(s, name, kind, br, war, prolif, cap, slow, lateyr)

                mu = mu + loc

                sg = sg + spr



                if SW["S1"]:

                    if k > 0:

                        ph = np.clip(phi_w + PHI_OFFSET[name], 0.0, 0.999)

                        idio[(s, name)] = ph * idio[(s, name)] + np.sqrt(1.0 - ph ** 2) * rng.standard_normal(n)

                    zi = idio[(s, name)]

                else:

                    zi = rng.standard_normal(n)



                z = math.sqrt(R.RHO) * c + math.sqrt(1.0 - R.RHO) * zi



                if SW["S5"] and name == "capable_actors" and D07_SD[s] > 0:

                    sdy = D07_SD[s] * min(1.0, max(0.0, (y - 2025) / 2.0))

                    extra = np.sqrt(np.maximum(0.0, sdy ** 2 - sg ** 2)) if sdy > 0 else 0.0

                    mu = mu + extra * zD



                if name == "defense_containment" and SW["S4def"] and k > 0 and ref is not None:

                    sh = beta * (np.log1p(Lprev[s] / L0[s]) - math.log1p(ref[(s, y - 1)] / L0[s]))

                    mu = mu + np.clip(sh, -1.5, 1.5)



                # Scenario perturbation parameters for defense uplift and exploit diffusion

                if diffusion_uplift != 1.0 and name == "capable_actors":

                    mu = mu + math.log(diffusion_uplift)

                if defender_uplift != 1.0 and name == "defense_containment":

                    mu = mu + math.log(defender_uplift)

                if patch_lag_factor != 1.0 and name == "success_given_exposure":

                    mu = mu + math.log(patch_lag_factor)



                if kind == "lognormal":

                    part = np.exp(mu + sg * z)

                elif kind == "fraction":

                    part = inv_logit(mu + sg * z)

                    if name == "exposed_share" and SW["S4dep"]:

                        part = part * np.exp(-cumS[s] / Vp[s])

                else:

                    part = 1.0 - inv_logit(mu - sg * z)



                # Consistency hierarchy: ICS operators are bounded by general IT operators

                if SW["S5"] and name == "capable_actors":

                    if s == "it":

                        itact = part

                    elif s == "ics" and itact is not None:

                        part = np.minimum(part, itact)



                d[name] = part

                tot = tot * part



            cnt = d["capable_actors"] * d["campaigns_per_actor"] * d["exposed_share"] * d["success_given_exposure"]

            cumS[s] = cumS[s] + cnt

            L = tot

            Lprev[s] = L



            out["L"][s][y] = L

            out["b"][s][y] = L * incr[s]

            out["rep"][s][y] = L / d["reporting_multiplier"]



            if y in keep:

                out["parts"][(s, y)] = d



    return out





def total(out, key, y):

    """Aggregate total across all sectors for a specified metric and year."""

    return sum(out[key][s][y] for s in SECT)





def wq(a, w, qs=(0.1, 0.25, 0.5, 0.75, 0.9)):

    """Calculate weighted quantiles."""

    idx = np.argsort(a)

    cw = np.cumsum(w[idx])

    cw = cw / cw[-1]

    return [float(a[idx][np.searchsorted(cw, q)]) for q in qs]





def ess(w):

    """Compute Kish effective sample size."""

    return float(w.sum() ** 2 / (w ** 2).sum())

def weights(out, use_as35=True, use_o5=True, use_o2=True, normalise=True):

    """Compute Bayesian importance weights based on empirical observation likelihoods."""

    lw = np.zeros(len(out["us"]))

    pf = out["parts"][("fraud", 2025)]

    Lf = out["L"]["fraud"][2025]

    usrep = Lf / pf["reporting_multiplier"] * out["us"]



    if use_o2:

        lw += -0.5 * ((np.log(O2) - np.log(usrep)) / 0.7) ** 2

    if use_as35:

        lw += -0.5 * ((np.log(AS35) - np.log(out["b"]["it"][2025])) / 0.9) ** 2

    if use_o5:

        lw += -0.5 * ((np.log(O5C) - np.log(1.0 - out["parts"][("it", 2025)]["defense_containment"])) / 0.5) ** 2



    if not normalise:

        return np.exp(lw)



    w = np.exp(lw - lw.max())

    return w / w.sum()





def baseline_post(n, seed, growth_discount=0.0):

    """
    Resample the baseline posterior distribution fit to historical FBI IC3 data (2015-2022).
    Returns real global non-AI counterfactual baseline per year.
    """

    rng = np.random.default_rng(seed + 1000)

    M = 2_000_000

    Z = V.Z



    def logit(p):

        return np.log(p / (1.0 - p))



    def inv_logit(x):

        return 1.0 / (1.0 + np.exp(-x))



    r = np.random.default_rng(2026)

    A0 = 360.0 * np.exp((math.log(800.0) - math.log(150.0)) / (2.0 * Z) * r.standard_normal(M))

    g = 0.08 + (0.14 - 0.02) / (2.0 * Z) * r.standard_normal(M)

    us = (1.0 / 3.8) * np.exp(math.log(1.5) / (2.0 * Z) * r.standard_normal(M))

    c = logit(0.14) + (logit(0.25) - logit(0.08)) / (2.0 * Z) * r.standard_normal(M)

    d = 0.15 + 0.15 * r.standard_normal(M)



    YRb = np.arange(2015, 2023)

    NOM = np.array([1.1, 1.45, 1.4, 2.7, 3.5, 4.2, 6.9, 10.3])

    CPI = np.array([237.0, 240.0, 245.1, 251.1, 255.7, 258.8, 271.0, 292.7])

    LR = np.log(NOM * 322.0 / CPI)

    ll = np.zeros(M)



    for t, y in zip(YRb, LR):

        mu_pred = np.log(A0) + g * (t - 2024) + np.log(us) + np.log(inv_logit(c + d * (t - 2024)))

        ll += -0.5 * ((y - mu_pred) / 0.20) ** 2



    w = np.exp(ll - ll.max())

    w = w / w.sum()

    idx = rng.choice(M, size=n, p=w)

    g_eff = g[idx] * (1.0 - growth_discount)



    return {y: A0[idx] * np.exp(g_eff * (y - 2024)) for y in YEARS}, ess(w)

    ta = {y: base[y] + tb[y] for y in YEARS}



    res["b"] = {str(y): {**calc_quantiles(tb[y]), "mean": float((w * tb[y]).sum())} for y in YEARS}

    res["a"] = {str(y): calc_quantiles(ta[y]) for y in YEARS}

    res["L"] = {str(y): calc_quantiles(V.total(out, "L", y)) for y in YEARS}

    res["rep_global"] = {str(y): calc_quantiles(V.total(out, "rep", y)) for y in YEARS}

    res["rep_us"] = {str(y): calc_quantiles(V.total(out, "rep", y) * out["us"]) for y in YEARS}

    res["sector_b"] = {s: {str(y): calc_quantiles(out["b"][s][y]) for y in (2025, 2030, 2035)} for s in SECT}

    res["baseline"] = {str(y): calc_quantiles(base[y]) for y in YEARS}



    res["ai_share"] = {

        str(y): dict(

            ratio_of_medians=float(wq(tb[y], w, (0.5,))[0] / wq(ta[y], w, (0.5,))[0]),

            frac_worlds_gt_50=float((w * (tb[y] / ta[y] > 0.5)).sum()),

        )

        for y in YEARS

    }



    res["p_a_above_ceiling"] = {str(y): float((w * (ta[y] > ceiling[y])).sum()) for y in YEARS}



    bshare = dict(fraud=1.0 / 3.0, it=1.0 / 2.0, ics=1.0 / 3.0)

    res["p_sector_above_bound"] = {

        s: {str(y): float((w * (out["L"][s][y] > bshare[s] * ceiling[y])).sum()) for y in (2030, 2035)}

        for s in SECT

    }



    return res





def main():

    """Execute calibration filter and write posterior summary JSON."""

    pilot = V.run(N, SEED, {**SW, "S4def": False, "S4dep": False})

    w0 = weights(pilot)

    ref = {(s, y): wq(pilot["L"][s][y], w0, (0.5,))[0] for s in SECT for y in YEARS}



    out = V.run(N, SEED, SW, ref=ref, keep=(2025, 2026, 2030, 2035))

    w = weights(out)

    base, bess = baseline_post(N, SEED)



    res = summarize(out, w, base)

    with open(OUT, "w", encoding="utf-8") as f:

        json.dump(res, f, indent=2)



    print(f"Calibration completed: ESS = {res['ess']:.0f}, output saved to {OUT}")

    return 0





if __name__ == "__main__":

    sys.exit(main())
